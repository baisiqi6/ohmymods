Kingdom Enhanced Mod V11.0.0 版本更新说明（Mac ARM64）
2026-10-25

适用平台：Apple Silicon Mac（原生 arm64），Kingdom Two Crowns: Call of Olympus
2.4.0 r23485（Unity 6000.0.61f1）IL2CPP / BepInEx 6。
仅支持与包内 game-lock.json 四指纹逐一匹配的非 Steam 锁定 DMG 实验构建；不支持
Steam 版、其他 2.4.0 构建、Mac x64 / Rosetta、Windows 2.4.3 或 Android。
本包不含游戏本体、个人配置或存档。本批只发布 Mac ARM64；Windows 2.4.3 与
Android 未发布，也不由本说明宣称已适配或已验收。

版本号：11.0.0（用户指定的一次性里程碑，仅此一次）。
日志 build：11.0.0-mac-arm64。
包名、package-manifest.json 版本与 SHA-256 以对应 GitHub Release 和包内
package-manifest.json 为准；本文件不写死尚未生成的产物哈希。
本版以当前 Mac 已安装的 default-net6.0 内容为基线，从上次正式版 v10.8.35（Windows）起的
玩家可见内容累计去重；不把未安装候选或 Windows 2.4.3 / Android 分支混入。

一、本批新增与变化

1. 宝石盾卫（默认关闭；所有世界，仅单机）
   位置：F5 / Ctrl+F10 →“MOD角色”页→“宝石盾卫”；
   配置文件：[HeavyShield] Enabled=false。
   4 宝石解锁盾模，6 金币购买盾具；每岛左右各 1 个基础席位，左右各再花 2 宝石
   可扩至 2 席。盾卫持盾 40 点耐久，格挡与盾击表现按当前实现；同一旗队
   每侧最多 1 名盾卫随旗。脱战约 6 游戏秒后返店，店匠约 8 游戏秒完成维修，
   不额外收费。身份、付款和保存记录在确认后才允许继续付费；关闭功能保留
   已购记录。密集围攻、实际维修耗时、跨岛恢复与其他平台仍另行验证。

2. 跨世界坐骑与双探索岛（实验；默认关闭；希腊单机普通战役）
   位置：F5 / Ctrl+F10 →“世界”页→“跨世界坐骑”；
   配置文件：[World] CrossWorldMountsEnabled=false。
   地图下方新增两座探索岛，16 个坐骑获取点按 8+8 分配；各有独立获取设施、
   紧凑下排与弯月岛形，详情页显示坐骑剪影。每个获取点每战役最多一处；
   已生成旧岛不追插，启用开关不会回填已访问的空岛；彩虹小马的新获取点仍需原生
   活动资格；联机暂不支持。
   已记录第一座岛的设施、标记、剪影、岸外单船、保存后冷读与地图往返；
   第二座岛的自然抵达、旧空岛回填、全部坐骑技能与主客同步尚未由第一岛样本代验。

3. 十金币宫廷与 400u 场景
   普通希腊来源岛出现红色入口“十金币 · 进入天朝”。投满 10 金币后按原生付款
   进入约 400u 宽的宫廷场景；宫廷门按 ↓ 免费返回来源岛，不经第二次付费。
   宫廷按固定（sealed）产品档运行：不提供 QA、免费试玩或诊断入口，环境变量不能打开
   这些分支；收费、已付费责任、保存与回程使用同一份责任记录，异常时停止推进
   而不是猜测补账。本次记录的真实链为 Mac ARM64 2.4.0 单机：10 币进入 →
   400u 场景 → 原生保存退出 → 新进程宫廷冷读 → 免费回程 → 来源岛冷读。
   舞女/荷花只做了有限动作采样，Menu 帧停；不构成全部动作或连续 60fps 观感验收。

4. 钱袋视觉扩展到各世界
   钱袋 UI 的 2 倍外观与固定位置偏移从希腊扩展到已启用 MOD 的所有世界；
   钱袋内金币保持原世界尺寸。本批只扩展显示范围；钱包容量与收币/掉币、经济
   业务、存档结构沿用既有实现，未在本批改动；不宣传“容量翻倍”或“实测 600 币”。

5. 皇冠窃贼恢复原生速度（PC / Mac 主线）
   移除 Mod 对皇冠窃贼水平 walk / run / jump / charge 速度与两个水平冲量的
   0.75 倍写入，最终数值由原生逻辑负责。不是新增加速；跳跃竖直力、攻击间隔、
   伤害、索敌与其他敌人不变。Android 分支保留其独立默认关闭开关，不在本
   Mac 包内。

6. 忍者 / 狂战士商店扩至更多世界
   Europe 与 Dead Lands 同时提供忍者与狂战士；Shogun 增加狂战士并保留原生
   忍者；Norse 增加忍者并保留原生狂战士与盾店；Greek 维持既有适配。
   相关忍者池与藏身点范围随计划调整。四个新增世界的完整购买→转职→战斗→
   迁址→存读档 / 联机尚未统一 Native 验收。

7. 其它纳入本批的改进
   - 常驻时间与银行 HUD 增加“储存钻石”只读显示：读取当前战役库存，只显示
     一次，未就绪或不可信显示“—”，不合计本机钱包。
   - 商店闲置展示人物与照明独立、库存搬迁保护；英雄 / 骑士身份持久化改进；
     火铳职业在原生保存同期记录，保留与原生存档精确匹配的配对备份。
   - 地图资源图标按岛归属；字体与静态文本性能改进；长按连续购买与原生购买
     范围衔接；墙基密度选项（默认 1 倍原生，最高 4 倍，联机整体跳过）。
   以上为合并后的玩家可见概括，不逐条展开内部返修；未逐项做 Mac 实机验收。

二、安装与升级（Mac ARM64）

1. 完全退出游戏。先备份游戏存档目录（此构建通常为
   ~/Library/Application Support/nl.noio.kingdom-two-crowns/）与旧包的
   BepInEx/config/，尤其 BepInEx/config/KingdomEnhancedMod/ModSave/。
2. 解压新的 Mac ARM64 发行包，得到新的包文件夹；不要覆盖旧包目录。
   只把旧包的 BepInEx/config/ 复制到新包同位置。不要复制 core、plugins、
   dotnet、cache、interop 或 unity-libs；它们随包更新，缓存会重建。
3. 用新包启动。启动日志应出现
   `Loading [KingdomEnhancedMod 11.0.0]` 与 `build=11.0.0-mac-arm64`。
4. 首次启动可能需要联网下载 Unity 基础库并生成 interop，耗时数分钟；
   本包未做 Developer ID 签名与 Apple 公证，首次放行与 quarantine 处理见
   package/README.md。不要用 xattr -cr 递归清除整个文件夹。
5. 旧配置与 ModSave 保留；重派骑士风格后身份附加档可能升级为 schema v4，
   旧版 DLL 不能读取 v4。回退旧版前须同时恢复升级前的游戏存档与旧版
   ModSave，只保留旧包文件夹不足以保证回退。

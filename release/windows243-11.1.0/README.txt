OhMyMods / Kingdom Enhanced Mod 11.1.0 — Windows x64
适用：Kingdom Two Crowns: Call of Olympus 2.4.3 r23537，Unity 6000.0.66f2，IL2CPP。
本包不含游戏本体。仅支持启动器校验通过的这一固定构建；不支持 Windows 2.4.0、
其他构建、Mac 或 Android。Windows 2.4.0 继续使用历史 v10.8.35。Mac 正式包仍为 v11.0.0。

安装与启动

1. 完全关闭游戏，先备份原生存档和旧 BepInEx/config，尤其是
   BepInEx/config/KingdomEnhancedMod/ModSave。常见原生存档在
   %USERPROFILE%/AppData/LocalLow/noio/KingdomTwoCrowns/Release。
   启动器不是备份工具；它使用当前 Windows 用户的正常存档。
2. 将完整包解压到 KingdomTwoCrowns.exe 所在目录，不要多套一层。升级时先保留旧包
   作为回退副本，再按本包完整文件集更新；不要混用其他版本的 core、interop、dotnet、
   unity-libs 或 Mod DLL。保留自己的 KingdomEnhancedMod.cfg 与 ModSave；本包不含它们。
3. 使用包内 Windows 启动器；历史名称 ohmymods-win243-preview.cmd 作为兼容入口保留，
   它实际加载本次正式版。若提示 Missing file / hash mismatch / Unexpected file，先停止，
   核对游戏版本和解压完整性；不要删除校验绕过启动。不能直接换游戏本体版本继续使用绑定。
4. 首次正确启动后，日志应显示 Loading [KingdomEnhancedMod 11.1.0]，
   build=11.1.0-win-x64。F5 或 Ctrl+F10 打开面板，设置自动保存。

使用方式

- “MOD角色”页提供火铳铺、英雄驿站、金币哥布林、宝石盾卫及相关选项。
- 宝石盾卫默认关闭；4 宝石解锁盾模，6 金币购买盾具；每岛左右各1席，
  每侧可再花2宝石扩1席。盾有40耐久，脱战后返店由店匠免费修补；同侧旗队最多1人。
  若提示“存档身份待核验，暂停购买”，不要反复付款，附日志反馈；旧档自动修复不预付。
- “世界”页跨世界坐骑默认关闭，仅希腊单机普通战役；两岛各8个获取点。
  两座岛分别提供一次性28颗宝石奖励，共56颗；重进不重复发放。已生成旧岛可补一次
  宝石箱，但不会因此回填旧空岛的全部坐骑设施。获取仍受原生资格与解锁条件约束。
- 付费火枪手留在购买岛，不随船运输；历史已登船且身份可确认的火枪手会归还职业状态，
  目的地按普通弓箭手处理。未知身份保留保存保护。弩手运输规则不变。
- 快速购买覆盖火铳铺。原支持商店保留长按续购；其他单次至少7金币的购买仅加速
  当前一笔，完成后需松开重按，不自动连续升级。原生价格、库存和付款资格不变。
- 忍者/狂战士扩展：Europe、Dead Lands均提供两者；Norse增忍者并保留原生狂战士/
  盾店；Shogun增狂战士并保留原生忍者；Greek保持既有配置。
- 钱袋放大适用已启用Mod的各世界；容量沿用已有实现，不将外观倍率等同于容量倍率。
  时间/银行HUD的“储存钻石”显示当前战役库存，不是君主钱袋余额。
- 骑士风格、英雄弓箭手、火枪编队、税收助手、自动补货、宠物/隐士保护、守军站位、
  普通远距夜袭出发余量、地图/墙位选项等共同功能继续保留，按面板开关使用。
- 皇冠窃贼恢复原生水平速度，过去的0.75倍降速已退役。

本次发行锁定用户已实玩的Windows修复链。已有玩家确认：第一坐骑岛出航、坐骑生成、
地图剪影、保存退出及新进程重进仍在岛上正常。发行重构建的源码、业务IL、资源、
依赖和启动检查另留回执；构建/主机测试不是所有玩法的实机验收。

- 人口增长导致40～50FPS的问题仍在排查，本版不承诺改善；临时性能计时不随正式包提供。
- 本Windows链未接入Mac的付费400u宫廷；不因版本号较新宣称平台功能完全一致。
- 第二坐骑岛/全部技能、四个新世界商店完整流程、跨岛返回、联机尚未统一实测。
- 旧存档盾卫首次购买与缺失身份恢复、旧空岛补设施另有待办；不要把本包当作通用修档器。
- 曾见首次出航的 Knight.EmbarkArchers 集合变动异常与 Forest 容量日志，冷重进未重复；
  根因未定，保留后续调查，不声称所有日志均无异常。

排查资料收集工具（带工具的新构建，或另外解压工具补充包后）

将三份工具文件放在 KingdomTwoCrowns.exe 同一目录，双击“一键收集排查资料.cmd”。
它会复制当前用户的游戏日志、原生存档、OhMyMods 配置和附加档，生成 ZIP 并打开结果目录。
默认结果位于 %LOCALAPPDATA%\OhMyMods\Diagnostics。工具不上传、不修改原档、不结束游戏。
ZIP 含个人游戏资料，只私下发送维护者。运行中或缺件时摘要会注明，不作为一致备份恢复。
历史已发布的 v11.1.0 ZIP 不会自动增加工具；可另取小工具补充包，游戏插件无需替换。

Kingdom Enhanced Mod V9.14.24 版本更新说明

2026-09-23 · 适用 Kingdom Two Crowns: Call of Olympus 2.4.0 / BepInEx 6

完整包：KingdomEnhancedMod_v9.14.24_IL2CPP.zip。版本号、日志 build 与发布标签分别为 9.14.24、9.14.24、v9.14.24；不适用于 Mono / UMM。
本版汇总公开 v9.5.13 之后的更新，共 4 项新功能与 4 项修复。本批同日先后发布两个版本：9.14.23（上午）为功能与修复批次；9.14.24（中午）为发布账目更正版——9.14.23 的发布说明列有“火枪手新长火铳”，但该批美术改动未随 PR 合并进发布包（Mac 侧交叉审查发现），9.14.24 将其正式入包，两个版本的玩法代码相同。版本号按项目累计制计算，本批合计 9.14.24（账目见 VERSIONING.md；自 9.5.13 以来的逐条账目原件已丢失，本批按对外条目清单重建账目，不逐条凑数）。版本号不代表全部内容已完成实机验证。
已有内容继续保留：9.5.13 的弩手守家高抛修复、旧骑士身份恢复后再保存丢失修复、英雄箭矢穿墙归还补全、存储读取保护与商店计时、钱袋视口校正，以及更早版本的中世纪散射、举旗火枪后排、白天猎鹿、长按弹药续买、英雄驿站与火铳铺等；除本说明列出的条目外，行为与范围不变。完整当前数值见 MOD_USER_GUIDE_ZH.txt。

【升级须知】骑士身份附加档 schema v4（必读）
首次在 F5 面板的“骑士”分区重派骑士风格后，身份附加档会升级为 schema v4（用户修订代次 rev 字段）；旧版本 DLL 无法读取 schema v4。回退到旧版本前请备份整个 BepInEx\config\KingdomEnhancedMod\ModSave\ 目录。未使用该面板的玩家不受影响。

一、骑士风格分配面板（新功能；F5 → 新增“骑士”分区）
- 五种风格（中世纪/死亡之地/幕府/希腊/北境）各有步进器与预览小图；按加减按钮调整各风格人数，总量不变（剩余池守恒）。
- 便捷操作：“均分剩余”把剩余名额均匀分给各风格；“全部重洗”为开关，按面板规则重洗全部骑士风格。
- 首次见到的骑士自动均匀分配风格（先于旧档补写），一般无需手动操作。
- 待识别岛（换岛后身份上下文失配）可在面板执行“用户锚定再基线化”：应用后写入在下一次原生保存的存档形态 JSON 作用域；旧记录全部保留，骑士 GUID 保留。
- 无身份上下文（无绑定）时应用按钮禁用并显示原因，不会静默失败。
- 回退到旧版本与 schema v4 的限制见文首“升级须知”。
- 待实机：步进器/剩余池/均分剩余/全部重洗、旧档自动分配、待识别岛锚定再基线、无绑定时的禁用提示。

二、宠物与隐士防抓（新功能；F5 → 便捷页子开关，默认关闭）
- 开关门 = 全局 Mod 开关 && 本子开关；默认关闭，关闭时保持原版行为（怪物可抓走狗与隐士）。
- 开启后狗与隐士不被怪物抓走：狗挂 Droppable 防护回执，与隐士同款长生命周期机制。
- 已被抓走（Stolen 状态）的找回：开启开关的瞬间、以及之后每次读档各触发一次。狗找回 = 改回漫游状态 + 统一到当前岛 + 生成（跨岛召回，保留毛色/类型/主人）；隐士找回 = 释放 + 统一当前岛 + 保留玩家记录。
- 边界处理：同 ID 已在场时延后处理（防止脱节与 RPC 双注册）；船上还原窗口有船/船体标签守卫；找回条件失败（如目标岛未加载）时保持待办，并在同世界自动重试。
- 行为变化：隐士防绑架从旧版“全局开关下生效”移到本开关下，默认关闭。

三、狗跨岛召回（新功能；不依赖防抓开关）
- 换岛后狗被留在旧岛时，读档/换岛自动把狗召回当前岛（漫游状态的狗按原生生成路径召回当前岛）；无需玩家操作。
- 被偷（赎回玩法状态）/被锁/被拾起状态不干预；同 dogId 已在场不重复生成；出航组滞留快照与场景还原有守卫。

四、火枪手新长火铳外观（新功能；v9.14.24 正式入包，纯外观）
- 内容：全新 67 帧动作表、7×3 短尾焰弹丸（pivot 锚在弹头中心）、五帧枪口焰；商店、侧枪架与掉落道具的全套贴图同步；Aim 姿态枪口锚为 (47,17)。
- 纯外观：伤害、射速、目标选择、池化与弹道逻辑均不变。
- 入包说明：该批美术此前被列入 9.14.23 发布说明，但未随 PR 合并进 9.14.23 发布包；9.14.24 正式入包，玩法代码与 9.14.23 相同。

五、修复：火枪手出征编队攻击怪物传送门
- 根因（双层）：目标过滤器无条件排除了门类标签——只镜像了原生“自由站立”半边，漏了编队/守位/乘船可射/骑士冲锋四个绕过臂；运行时重选器还会把原生选中的门替换成普通地面敌人或空。
- 修法：四个调用点全部改为带射手状态的谓词（逐字镜像原生两层判定）；重选器“原生选中且我方放行则不替换”；弹丸发射时快照射手状态两位（防飞行中误伤门/被门挡弹）；读状态失败整组回落“自由站立”（fail-closed）。
- 范围：守家行为不受影响（守家资格门结构性排除编队成员）。

六、修复：弩手举旗误转化
- 举旗编队不再把弩手转化为跟随弓箭手：在原生招募路径的编队门后加弩手身份判定。
- 火枪手不受影响；收旗后无残留。

七、修复：武士返队永不站桩（立即回防）
- 根因：旧逻辑三次抢目标失败即硬锁放弃返回；白天受击硬直且无目标时会彻底站桩。
- 修法：删除硬锁，改为阶梯降级——冲刺失败退避 2/4/6 秒后无限期步行回防，武士永远有回家目标；返程全程面向敌侧防御朝向；步行段允许挥刀自卫。

八、修复：税收官瞬移悬空
- 根因：助手接近金币的瞬移把空中飞行币的坐标（Y = 飞行高度）当作落点，助手悬空出生且后续移动不回地面。
- 修法：接近瞬移的 Y 取助手自身高度（与 Z 轴同纪律）；扔出的空中币不再引发悬空。

安装与升级
1. 完全退出游戏，一起备份原生存档、BepInEx\config 与已有 MOD 附加文件（尤其骑士/火枪手身份记录）。标准原生目录为 %USERPROFILE%\AppData\LocalLow\noio\KingdomTwoCrowns\Release\global-v35；附加目录为 BepInEx\config\KingdomEnhancedMod\ModSave。首次进入旧存档前请先备份存档目录；使用“骑士”面板重派风格前同样需要备份该目录。
2. 将 KingdomEnhancedMod_v9.14.24_IL2CPP.zip 完整解压到 KingdomTwoCrowns.exe 所在目录，不要多套一层目录。包含 BepInEx 6 与 dotnet 运行时，不含游戏本体、个人配置或存档。
3. 现有设置保留；本版新增 F5“骑士”分区与便捷页“宠物与隐士防抓”子开关（默认关闭）。恢复备份时应使用同一时间点的原生存档、配置和附加文件。
4. 启动日志应显示 Loading [KingdomEnhancedMod 9.14.24] 与 build=9.14.24；首次生成缓存需等待。
5. 回退到旧版本前：如已在“骑士”面板重派过风格，请先备份整个 ModSave 目录（schema v4 见文首升级须知）。

验证范围与已知限制
- 本批 4 项新功能与 4 项修复均未完成游戏内实测；当前证据为构建（0 警告 0 错误）与针对性回归测试全绿。代码与接口验证不等于游戏实测，版本号不代表已实机验收。
- 待实机：骑士面板（步进器/剩余池/均分剩余/全部重洗、旧档自动分配、待识别岛锚定再基线、无绑定时的禁用提示）、宠物与隐士防抓（开启瞬间与每次读档的找回、隐士行为变化）、狗跨岛召回（被偷/被锁/被拾起状态的不干预）、火枪手新长火铳外观与动作观感、火枪手出征编队攻击怪物传送门、弩手举旗不误转化、武士返队立即回防、税收官不悬空；联机需双方同游戏与 MOD 版本。
- 已知边界：骑士面板 schema v4 不可被旧版本 DLL 读取（回退前备份整个 ModSave 目录，未使用面板的玩家不受影响）；跨岛身份运输（英雄/火枪手身份绑定购买岛）仍未实现；带客机的主机不暂停游戏（原生语义）；自动补货无左右侧感知（按全局计数采购，行为与 v9.5.13 相同）。
- 既有未解决保持：英雄走/跑阈值动作切换、Beggar 乞丐穿地、个别弩手缩放回原值（本批未声明修复）；人口位置/物理日志只是诊断，不是修复。
- 身份记录仍依赖原生存档与 MOD 附加档精确匹配：不要把不同时间点的文件混用或删除附加档强行重建；火枪自动补货的“本次游玩确认消失”证明仍不持久保存。
- 反馈请附世界/岛屿、单机或主客机、面板设置、复现步骤及 BepInEx\LogOutput.log。

OhMyMods 一键收集排查资料（Windows）

1. 把本包三份文件解压到 KingdomTwoCrowns.exe 同一目录，不要放进 BepInEx。
2. 双击“一键收集排查资料.cmd”。不需要管理员权限或另外安装组件。
3. 完成后会打开结果文件夹，把其中 ZIP 私下发给维护者即可。
   若无法自动打开，按窗口显示的路径查找。

默认结果目录：%LOCALAPPDATA%\OhMyMods\Diagnostics
每次生成新的资料包，不覆盖之前的 ZIP。

收集内容：BepInEx 日志、Unity Player.log、原生 Release 存档、
OhMyMods 配置和 ModSave 附加档，以及现有发行清单。
游戏 EXE 与插件只记录版本及哈希，不复制游戏本体或运行库。
不收集其他 Mod 的配置，不自动上传，不修改或删除原档，不结束游戏。

遇到报错时可以先保留当前现场直接收集，不必为了收集而重启或再次保存。
运行中得到的是磁盘文件的活动快照，不能当成同一保存点的一致备份。
缺件、被占用、读取失败、超出限制或文件变化会在包内 manifest.json 中说明。
部分资料缺失时 ZIP 仍能发送；无法生成可用 ZIP 时，窗口会显示失败原因。

ZIP 中的日志和存档可能含账号名、路径等个人信息，请只私下发送维护者。
更详细的逐项结果和快照说明见 ZIP 内 README.txt 与 manifest.json。

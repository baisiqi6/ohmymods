# 商店素材制作准则

用户于 2026-10-06 明确：商店中的人物应站在地面上，与其他角色高度相近，并把它作为商店素材制作的一般准则。

建筑参考同世界原版的像素密度、配色和体积表达。用顶面亮部、下檐/内凹暗部、立柱厚度和前后遮挡形成空间；不要以大量细碎纹理或高饱和装饰替代建筑体积。

商人以同世界、同相机下的原生成年居民作身高参照，支撑脚对齐实际游戏地面或原生地基脚线。柜台可自然遮挡腿脚，但不能靠遮挡掩盖悬浮、站在柜台或人物过小的问题。建筑门洞/棚内空间适配人物，不能把人物缩小成摆件。离线固定像素数不能代替游戏世界中的比例核验。

人物单独动画层，不烘入建筑。每帧检查 PPU、pivot、支撑脚和朝向；角色缩放遵守现有只动 y 轴规则。接入前同时核验层序/遮挡、footprint、付款触点及与地面的关系。

必须明确区分三种交付：造型预览只验证方向；生产 atlas 要满足尺寸、帧表、透明边缘和运行接线；游戏实测才验证最终人物比例、接地、遮挡及画面观感。概念图不能直接标为可安装素材。

当前具体造型方向另见 [#176/#177 美术记录](../project-harness/tasks/shop-art-176-177/README.md)。这些店铺的造型选择不泛化为所有商店都必须有布棚、或都禁止布面。

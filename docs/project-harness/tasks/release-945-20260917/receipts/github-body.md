本版汇总 v9.0.0 之后的更新：

- 举旗时保留原有 4 名重装步兵、4 名弓手和船队，后排额外招募最多 4 名已有火枪手。首次升级测试请先收旗，再重新举旗。
- 火枪手白天猎普通鹿，不伤兔子等小动物及坐骑；保留原伤害、射速、射程和鹿的原生掉钱。矮鹿使用一次直线瞄准，不追踪目标。
- 长按连续购买加入投石车火药桶与希腊火塔弹药；自动补货统一只在白天进行，原有适用世界与金库成本不变。
- 恢复独立侧枪架，火枪手外观缩为 0.9，枪口改为五帧红色喷焰。
- 改进火枪与额外范围伤害的结算、密集命中查询、对象池清理和低帧率弹道处理，减少火焰特效的重复计算。

版本按项目累计规则由 **9.0.0 + 0.4.0 功能 + 0.0.5 修订 = 9.4.5**。规则与本次计算表已写入 [VERSIONING.md](https://github.com/baisiqi6/ohmymods/blob/v9.4.5/VERSIONING.md)，安装包内也有同一份文件。

适用 **Kingdom Two Crowns 2.4.0 IL2CPP / BepInEx 6**。完整包包含 BepInEx 与 dotnet 运行时，不含游戏本体、个人配置或存档。完全退出游戏并备份后，将 ZIP 解压到游戏 EXE 所在目录。保留已有设置，本次复用现有开关；火枪功能仍仅单机。

精确发布源码已通过完整构建及 99 个测试/编译项目；其中 5 套 xUnit 共 434 项通过。包内 306 项运行依赖与 v9.0.0 逐字节一致。

**实机边界：**新队形、鹿命中掉钱与回防、密集战斗帧耗时、跨岛和相关联机仍有待验项。英雄走跑切换、乞丐穿地及个别弩手缩放问题尚未宣称修复。代码回归不等于全部玩法已实测，详情见包内更新说明与用户指南。

## 实现行为
F5 / Ctrl+F10 → 自动补货：工匠、弓箭手、忍者、狂战士分别开关和设置目标1..200，首次默认关闭、目标15。白天从主城金库按店铺实际金币价格采购。目标按当前存活职业人数+该职业全部店内待领取工具+本mod在途订单计算。忍者白天钓鱼外观仍算忍者，弓箭手包含随从和塔岗。原生转职同步创建新职业，再移除旧体，视觉转职阶段新体已计入。

商店满槽不购买：10工匠+满4锤、目标15时等待；不突破原生容量，不造职业或新店。借用现有税收官最多2名，借用前归还旧金币claim并处理携币；其余税收官照常收币。采购者瞬移店旁，使用原生DroppableCurrency.MoveTo投币表现，每.2秒一枚，最后一枚后复核条件并调用一次native TransactionComplete；结束返主城。动画币fake且自动回收，不从玩家钱包扣款或制造可拾取真钱。

角色、库存事件维护缓存，复用既有税收官调度。仅首次启用、世界/岛/层变化、开关变化或有界故障恢复初始化枚举原生Kingdom._characters。稳定期不全场Find/Physics扫描，也不重复遍历角色名册或商店注册表。工具增减只重算相关商店；缺货时每2秒最多检查缓存中少量候选店的容量/施工/付款等门。这个功能仍有少量事件、上下文校验和动画成本，不能宣称零性能消耗。

暂停冻结进度；夜晚、职业关闭/目标达成、付款冲突、余额不足、身份/权限/世界失效会取消或等待。失败取消后该职业等2秒再尝试，避免频繁往返。真扣款与native购买位于同一同步函数；已扣款而native结果未知则封锁该店当前实例到世界重建，不盲目退款/重试。native涨价后合成的玩家选中状态通过原生Deselect清理，实际玩家支付/选择仍保护。

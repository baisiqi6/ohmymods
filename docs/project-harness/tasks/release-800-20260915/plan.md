# Release 8.0.0

用户在本地包完成后明确要求上传发布，并询问本机测试目录是否最新。本轮发布新的v8.0.0，保留既有发布和标签；游戏关闭时将同一正式包DLL同步到既有E盘独立副本，不启动游戏或覆盖配置、存档、MOD附加档。

功能基线为双尾长围巾候选7DD53270；8.0.0仅统一版本和构建日志。上一轮117项生产源码快照、68项目（56run/4xUnit共392项/8compile）、资源与方法体等价检查通过。本轮在确定的release commit干净工作树重新构建与打包，manifest必须记录精确GitCommit，不能上传先前未提交快照包并声称来自确定提交。

发布工程引用须与实际2.4候选一致：统一GameInteropDir并显式引用Assembly-CSharp-firstpass中的游戏Input，避免旧工程绑定到UnityEngine.Input。只调整构建引用，不修改玩法源码；最终与8.0候选逐方法体等价核验。

使用隔离Git索引按明确清单选择源码、测试、玩家文档和必要像素制作来源，保留当前工作树和索引，不混入个人日志/缓存/配置/存档或测试岛操作文件。以公开7.6.5源码为release父提交，只推新v8.0.0标签，不推master或修改旧标签。

完整包包含同一已验证306项运行依赖、本DLL、5份当前玩家文档和正式BUILD-MANIFEST。独立审核通过后创建草稿、上传并核远端size/digest，再发布为Latest并读回标签与发布状态。玩法未实测项与正式发布完成分开，英雄在线仍关闭，原有转向/淡出边界不宣称已修。

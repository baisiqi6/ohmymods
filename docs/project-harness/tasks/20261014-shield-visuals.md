## 证据与边界

人物细图外缘约 85.2% 为不透明纯黑，粗图约 69.2%。alpha 仅 0/255，载入为 Point/Clamp、无 mipmap，存在明确的烘焙黑轮廓。显示层仍复制原生材质与 PropertyBlock，因此额外渲染贡献尚未实测排除。

移动命令使用现有 `carrier.walkSpeed`；显示层按速度选档后，以固定时钟播放 walk 6帧9fps、run 8帧14fps、advance 6帧8fps。没有连续位移与循环相位的对应。直接乘 1.5 还可能跨过现有 walk/run 分类门槛，不能据此保证减少滑步。

## 本阶段：描边候选

只处理每格从外框四连通可达的透明区；与该区八邻接的不透明纯黑为候选。附近三像素内只接受有界的非高光材质色，材质不明或混杂时保留原黑。只改 RGB，alpha、帧格、脚线、PPU、pivot、内部非外露线条以及非候选像素保持。

B 私有预览修改 detail 45,683 像素、coarse 25,035 像素；保留无法可靠判别材质的候选。两个密度均保持 509 个有效帧和三个空尾格。这个结果只说明素材差分，不是实际游戏中黑边全部消失的验收。

生产生成器从不可变的上述 Git 基线提取两张 PNG 并验证输入 SHA，不读取已处理的当前 PNG 当输入，避免反复加深或变浅。单独的验证器独立确定外透明区，拒绝 alpha、内部线、非黑外缘、空尾格等越界修改；不导入生成器来计算预期颜色。

旧行走修复的完整像素检查仍对其 pre-outline 中间产物执行。新增验证再证明该中间产物等于本次颜色处理输入、最终 alpha/脚线及鞋部连接保持。不能把旧检查的“仅24格改动、原调色板不变”套在新增全动作颜色变更上。

实现与验证按顺序执行：生成只写显式自有输出目录；复核最终两图与已选 B 的解码像素一致；执行独立拒绝反例和原有素材/表现测试；使用当前 2.4 interop 纯编译并禁用部署；独立审查后提交和推送 Draft。当前阶段没有动作、移动或原生材质代码改动，不关闭完整 Issue，不自动合并或安装。

## 后续：真实步态标定

离线同位移 9/6 fps 对照明确使用合成轨迹，不能当作游戏录屏或最终标定。当前 PNG 没有可靠的脚身份、plant/release 和物理 stride 元数据；最低不透明行或包围盒不能代替接地标注。

下一次有界隔离测试需记录同一合法盾卫的连续 root x、同 root 刚体速度、时间、姿态/动作/帧号以及只读 walkSpeed/runSpeed，检查脚部相对地面滑动。读档、暂停、瞬移、世界或 life 改变时不跨边界积分。只有 live stride 和各循环接地相位有依据后，才确定位移驱动的 normalized phase；walk/run/advance 的移动循环与 equip/stow/block/bash/break、起停和休息时钟分离，6↔8 帧转换保持归一化相位。不得改真实移动字段、Mover 的 x 缩放或用全场扫描补偿。

生成、自动验证、独立审查、构建、安装和游戏实测分别记账。Windows 与其他平台未因 Mac 离线结果而通过。

## 2026-10-14：原生只读采样

Mac ARM64 当前 2.4.0、正常累计 DLL `36faec77` 的独立副本完成了一次只读观察。先前两轮对 managed `TickRoot` 的诊断挂钩没有成功，均无步态样本；第二轮完整异常定位到第三方 `ILHook` 构造链的 NullReferenceException，底层初始化根因仍未确认，未修改 detour backend 或安全设置。本轮改用已有正常 Mod 补丁的原生 `Mover.Update` 入口，运行时 54 项结构验证通过、正常 owner 与新增 postfix 均被核实。

两名合法盾卫各记录 750 行，共 1,500 行；首个目标开始约 30 秒后按预算停止，reserved/written/flushed 均为 1,500，采样、写入及 flush 故障均为 0。样本覆盖自然 BackWalk，不覆盖稳定 BackRun/Advance。`Animator.GetFloat("Speed")` 全部未取得有效值，不能拿它代表播放倍率或校准依据。数据在 Mover.Update 的 postfix 内、finalizer 与视觉 LateUpdate 执行前取得，相对其他 postfix 顺序未知；Pose/LastFrame 可能为此前已应用或注册初始状态，不能与当前位置组成同显示帧脚点。独立离线统计仅保留分段位置、刚体读值和粗帧变化，不推导实机步幅或修复倍率。

测试通过菜单正常保存退出，原生启动器真实退出码为 0；关闭后稳定观察约 32.27 秒、恢复后严格原件观察约 31.52 秒。独立两次完整回读确认 normal/game/save/prefs/logs 均严格等本轮新备份，相关游戏、启动器与权威 active 均为 0，正常 DLL 保持 `36faec77`。本轮没有安装 B 图集、改游戏移速或步频代码；隔离采样不是这些改动的实机验收。

退出监视新增的同一 launcher 真实 wait 过渡通过了纯反例测试；成功收尾后没有持久化该细分 active 快照，因此本轮是否实际经过该窄分支为 UNKNOWN，不能宣称原生覆盖。此前失败轮次及其恢复证据保留，不改写为成功。

v5.0.0 汇总 v4.5.0 之后的骑士战斗、出征跟随、希腊舰队与经营调整。适配游戏 2.4.0 IL2CPP / BepInEx 6。

## 主要更新
- 修复守墙规则导致骑士随从出征留在墙下的问题，保留动态跟随。
- 希腊小船新骑士乘员限定希腊小队；举旗时按同侧可用小队与船数较小值配队，最多4艘，避免重复预留同一队。
- 希腊骑士小队火焰攻击持续8秒、冷却15秒；修复跨世界随从火箭资源缺失和中世纪剑风排序接口异常。
- 武士主动返队，前冲及返队冲刺均有伤害；新增浅白残影，仅防御性后退速度提高至3倍。
- 时间HUD加入银行存款；新装乞丐刷新默认120秒、每帐篷4人。
- 希腊农场目标猫数6→4，处理旧版多放的空闲Mod猫；移除旧逐箭日志，补员诊断改为有界记录。

## 安装
下载下方 **KingdomEnhancedMod_v5.0.0_IL2CPP.zip** 完整包，退出游戏、备份存档后，将全部内容解压到游戏EXE所在目录。已包含BepInEx 6与dotnet运行时；不适用于GOG Mono版。
升级保留个人配置。老玩家如需120秒/4人设置，请在面板中调整；包内不覆盖个人Mod配置。

## 验证与边界
对应改动已通过构建、独立审查及回归检查，发布包另做启动恢复验证；真实战斗、登船、换岛和联机仍需持续实测。
- 新残影尚未完成实战画面验收，目前由本地/主机触发，未增加客机残影触发同步。
- 舰队数量是当前同侧可用配对上限，等待登船期间可能暂时空船；旧档已上船的其他风格队伍保留当前航程，主跨岛船不套用该风格限制。
- 猫调整仅希腊单机/同机分屏；原生、被抓或跟随玩家的猫保留，可能超过4只。读档并恢复运行约5秒后处理。
- 补员异常仍在收集证据，没有宣称全部修复。希腊火双端表现、出征跟随等新行为仍待更广泛实测。

详细更新、安装指南和构建来源见包内文档及BUILD-MANIFEST.txt。

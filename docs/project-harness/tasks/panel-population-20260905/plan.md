# 人口设置与面板改版

默认维持每营地5人、每6秒补1人。新增范围1–20人/1–120秒，由既有0.5秒主线程协调周期读取配置，禁新增全场扫描、补员突发、网络越权。人数下降仅停止补员；旧读档自动删除路径停止使用。

# bank-assistants-005 — 唯一主银行家与四名跨世界银行助手

## 目标

- 希腊世界继续只保留一个原版 `Banker` 作为国库、利息、提款、城堡门和存档的唯一管理者。
- 使用欧洲、幕府、Dead Lands、北境四套银行家动画外观，各生成一名不带 `Banker` 行为的银行助手。
- 主银行家保持原生状态机与增强移速，但收币管辖区收紧为城堡左右两侧从内向外数第二道墙之间；这个区域之外的
  玩家普通金币，无论仍在领地内还是已经在外墙外，落地超过 3 秒后均由中央调度器分配给助手。
- 北境外观助手仅调整视觉高度为 y=1.2；助手连续收同一批金币时，下一枚距离不超过 6 个世界单位就
  直接跑过去，超过该阈值才瞬移到目标附近。

## 安全边界

- 仅 IL2CPP 2.4.0 发布线；Mono 冻结。
- 场景中始终只有一个 `Banker` 组件和固定 NetID 903；助手不得带 `Banker`、`Persistent`、`Wallet`，不得计算利息、提款或开关城堡门。
- 只有 world-authority 可以认领/回收金币和修改主银行家的国库；客户端只接收助手池生成和位置同步。
- 每枚金币同时最多分配给一名助手；只处理 `DropType.Player` 的普通金币，不处理宝石、商店物品或其他掉落物。
- 中央扫描器统一扫描，助手不得各自执行全场资源扫描；扫描频率不高于 2 Hz。
- 助手成功拾取金币的同一权威事务中立即把 1 枚金币记入唯一主银行家，消除换岛/读档时的在途丢币窗口；满载或暂时无目标时回城仍作为视觉交付与容量节奏。
- 不触碰 Steam、共享存档和当前正式 zip；候选只允许构建并部署独立测试副本。

## 设计契约

1. 2.4.0 只有一个 `Banker` prefab，通过动画覆盖形成五套外观：欧洲、幕府、Dead Lands、北境、希腊。
2. 希腊外观留给主银行家；助手固定使用另外四套外观，数量严格为四。
3. 助手使用独立同步池和 `PositionSync`，不复制原 Banker 的固定网络身份或持久化组件。
4. 用 `Kingdom.GetWall(Left, 1)` 与 `GetWall(Right, 1)` 的位置定义主银行家内城管辖区（有序列表从 0 开始，索引 1 即从城堡向外数第二道墙）。只有左右第二道墙都有效时才启用该边界；加载或尚未建齐时，两侧第一道墙都有效则对称回退到索引 0，再否则回退当前外墙区间，禁止左右混用不同层级。金币首次在该管辖区之外被中央扫描器观察时开始计时，满 3 秒后才可分配；主银行家的认领入口必须拒绝管辖区之外的玩家普通金币。
5. 中央调度器同一批次只指定一名当前收税助手，让它连续处理成熟金币；其他三名不得为同一批金币一起瞬移。当前助手达到容量、失效或完成批次后，才按轮转顺序换下一名。首枚或距当前助手超过 6 个世界单位的目标允许近距瞬移；同一批后续目标在 6 单位内时保持当前位置并直接跑去拾取，不发送多余的全位置传送同步。
6. 助手没有收税目标时在城堡附近、墙内的独立小区间低频巡逻，使用现有轻量位置同步和走路动画；不得复制完整 `Banker` AI，也不得各自全图扫描。四个助手到达各自巡逻端点后分别停留 2/3/4/5 秒再折返，不使用随机数，也不持续发送无意义的位置变化。
7. 主银行家使用增强配置：保留城堡附近原生游走逻辑，移动速度恢复为此前增强值，安全期全天不隐藏；金币扫描动态覆盖左右第二道墙，并由同一内城管辖判定保证身体不会追出该区。扫描频率需保持低频，不能因地图加宽产生每帧物理查询。若运行中重新启用 Mod，安全时立即恢复工作；攻城等不安全状态不主动出城开门。
8. 四种助手只改视觉 y：欧洲/幕府/Dead Lands 保持现有比例，北境助手 y=1.2；不得改 x 朝向或经济、碰撞、同步组件。
9. 助手虚拟容量跟随主银行家钱包容量；满载立即回城。金币经济所有权已在成功拾取时提交，回城不二次加账。
10. 保留现有跨岛共享存款，但废弃对 `IEnumerator` 起始时点的旧同步：日开始由主银行家先载入共享余额、原生只计一次利息、随后保存；真实存入/提款按城堡余额实际变化同步。客户端与未完成 priming 的初始化路径禁止写共享账本。

## 验收

1. 静态审查确认不存在第二个 `Banker`/NetID 903、重复利息、重复提款或客户端国库写入路径。
2. IL2CPP Debug 构建 0 warning / 0 error，checklist validator 与 `git diff --check` 通过。
3. 希腊实机出现 1 名主银行家 + 4 名不同外观助手；切岛、读档和 Pool 重建后不重复生成。
4. 左右第二道墙之间的金币不分给助手；主银行家能以增强速度收取。该区之外（包括仍处于外层领地内）的金币在 3 秒前不分配，3 秒后由一名当前助手连续处理。
5. 其余三名助手在城堡附近分散巡逻，不为同一批金币一起瞬移；首个/远目标近距传送，6 单位内的下一枚金币直接跑去，不出现逐枚闪现。满载/批次结束后回城轮换，成功回收时国库总增加量等于实际回收金币量，回城不重复入账。
6. 北境助手视觉高度为 1.2，另外三种助手比例与朝向不变。
7. 单机日志无 duplicate NetID、Pool not found、NRE 或重复计息；联机主客均见四名助手且客户端不修改国库。

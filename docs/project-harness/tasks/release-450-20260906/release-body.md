王国增强 Mod **v4.5.0**，适配游戏 **2.4.0 IL2CPP / BepInEx 6**。

一、骑士风格与战斗差异

- 中世纪骑士：攻击距离和前向命中范围增加50%，用短剑风提示攻击范围。
- 死亡之地骑士及当前随从：攻击节奏提高到2倍，移动速度提高50%；实际频率仍受原生动作、目标和帧率影响。
- 北境骑士：自身金币容量与留币上限翻倍，提升承伤空间；不会凭空赠送金币。
- 幕府骑士：短距离冲刺攻击，冲刺期间无敌，并有白光和拖尾；冷却约3秒、最大行程7格，距离随从过远时停止继续发起冲刺。
- 修复跨世界风格的骑士动画加载与随从外观混用；希腊骑士继续保留现有行为。

二、弩手守家与箭塔

- 独立弩手夜晚守墙时分散到墙内中后段，通常距墙4～7格；窄地形会收缩站位范围。
- 统一守位纠偏入口，减少不同站位规则来回拉扯；逃跑、登船、骑士编队和玩家控制沿用各自行为。
- 塔内弩手射程按自身原值提高50%，通常从12提高到18；地面弩手保持12。
- 进出塔和单位回收时恢复对应射程，避免塔上的加成残留到地面。

三、法杖、人口设置与新面板

- 赫尔墨斯法杖友好巨魔转化数量上限提高到32，转化扫描范围扩大到原生的2倍。
- 乞丐刷新间隔改为1～120秒滑块，默认6秒；帐篷容纳上限改为1～20人滑块，默认5人。
- 调低帐篷容量只影响后续补员，不会删除已有乞丐。
- 重做设置面板的分区、配色和排版；F5或Ctrl+F10打开，修复部分IL2CPP环境下面板绘制失败的问题。

四、可选常驻时间与季节显示

- 在设置面板开启后，游戏画面显示总天数、当前整点小时、本季节第几天，以及下一季从总第几天开始。
- 季节使用图标与不同颜色区分，读取实际游戏季节安排；默认关闭，关闭后恢复原本画面。

五、稳定性与性能

- 修复近期骑士强化导致的启动闪退风险，并完善攻击中断、单位回收后的清理。
- 修复冲刺中关闭Mod后，幕府骑士回收时无敌和拖尾清理可能被跳过的问题。
- 多项定时扫描错峰执行，性能记录避免在同一个世界重复挂载；继续减少大规模单位场景的周期性开销。
- 保留此前塔基重叠修复、各风格随从外观修正及大蛇波次相关调整。

安装与升级

这是完整安装包，已包含BepInEx 6加载器与dotnet运行时，无需另找前置包。
1. 完全退出游戏，备份存档：%USERPROFILE%\AppData\LocalLow\noio\KingdomTwoCrowns\Release\global-v35。
2. 把ZIP内全部内容直接解压到包含KingdomTwoCrowns.exe的文件夹；不要多套一层版本文件夹。
3. 新装首次启动需要生成缓存，请等待；若未加载，退出后再启动。日志中应出现Loading [KingdomEnhancedMod 4.5.0]及build=4.5.0。
4. 从旧版升级可覆盖解压；包内不携带个人KingdomEnhancedMod.cfg，保留玩家原有设置。
5. 联机双方使用相同游戏版本和v4.5.0 Mod。联机异常请提供双方BepInEx/LogOutput.log及复现步骤。

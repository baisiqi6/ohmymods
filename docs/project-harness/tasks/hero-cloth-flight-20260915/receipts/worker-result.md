|---|---|---|---|

| 0.65 走 | 12.24px（仍在地面拖行） | 18.64px | 0px |

对照 repo 旧版：1.6 跑时尾部下降均值 12.23px、最小离地 0px、延伸 18.25px —— 即旧版在 1.2–1.6（operator 逐字指出的「常见跑速」）尾部始终低垂贴地，本次目标达成。

时间行为：起跑单步最大位移 2.00px/步（60px/s，无瞬跳），**1.1s** 达到「下降 ≤8px」；停下 0.57s 后明显回落、0.83s 恢复贴地静止。全程不穿地、段长误差 0、节点不高于肩部。

## 修改理由

1. 旧版在常见跑速下把尾部钉在地面（实测 1.6：tip 下降 13.36px、离地 0.14px、延伸 67%）。两个叠加原因：
   - `GroundContactBand` 让**贴地节点完全不吃水平推力**（`nodeX = grounded ? 0 : drivenX`），而抬升 `LiftGain=0.05·v²` 上限 3（v=1.6 时仅 0.13）几乎不抵消重力 → 落地的折叠段永远被重力压在 `FoldToFloor` 线上，只能等上层节点把地面线「抽」起来。
   - 旧版为了补救，藏了一条**瞬时水平锁定**：`if (speed >= 2f) drivenX = Min(drivenX, -speed)`。这是 operator 明确禁止的手段（v≥2 起作用的硬阈值：阈值前后形状不连续，且把水平加速度绝对值钉在速度量级上），也是「2.0 才算跑、1.2–1.6 不算」的根源。
2. 目标需要的是**有界、平滑、与速度连续**的展开包络：走（0.65）轻微、跑（1.2–2.0）充分、停下保留惯性再落回，且不能靠「永久抵消重力」或「瞬时锁水平」伪造。
3. 落地折叠段要被「带离地」，必须同时有(a) 足够但**有上限**的向后拖曳，(b) **严格小于重力**的气流抬升。物理直觉：缎带在自身气流里既被拖到身后，也被气流托起（动态压力），气流越强越接近水平，但永远存在一个向下的净重力分量。

## 参数意义与取值依据

| 常量 | 值 | 意义与选择依据 |
|---|---|---|
| `Gravity` | 9 | 不变。抬升恒 < Gravity → 静止绝不悬空 |
| `FlowAttackSeconds` | 0.5 | 包络上升时间常数（一阶）。足够「逐渐」（2–4s 窗口内充分展开），又不至于慢到不像跑 |
| `FlowReleaseSeconds` | 0.95 | 包络下降时间常数 → 停下保留约 1s 惯性，1–3s 内落回（实测明显回落 0.57s、复原 0.83s） |
| `FlowMax` | 4 | 包络上限（u/s）：展开力只看包络 → 力天然有界；瞬移另由 `TeleportSpeed` 拦 |
| `DragLinear` / `DragQuadratic` | 1.0 / 24 | 拖曳 q = 1.0·flow + 24·flow²：走轻微（≈6.2u/s²）、跑饱和。二次项保证走/跑对比清晰（走 0.65 的 airborne 拖尾 0.17u vs 跑 1.6 的 0.24u） |
| `MaxDrag` | 19.5 | 软饱和 `drag = 19.5·(1−e^(−q/19.5))`：光滑、有界、flow→0 时→0（静止零水平推力）。上限同时受旧版「3.5 跑速时尾部下降 ≥4.8px」约束 |
| `MaxLift` / `LiftHalfSpeed` | 4.2 / 0.9 | 抬升 `4.2·flow²/(flow²+0.81)`，永远 < Gravity；1.6 时 ≈3.2 → 有效重力 5.8，使拖曳 19.5 能把尾部抬到水平附近 |
| `AirDampingPerFlow` | 0.3 | 悬空节点速度保留 `0.90/(1+0.3·flow)`：气流吸收起跑甩尾。**这是「不甩过肩」的关键**：不加它时 1.6 起跑会把尾部甩到肩上方 4.3px；加了之后全程最高点 ≤ 肩（0.00px，实测） |
| `WindFade` | 0.6 | 风水平分量 × `1/(1+0.6·flow)`：静止时风照旧（与旧版逐位一致），跑动时只剩轻微调形（实测 ±1 风的形状差：静止 0.104u → 跑动 0.0045u） |

被保留的既有参数（未动）：`DampingPerStep=0.90`、`GroundFrictionPerStep=0.72`、`GroundContactBand=2px`、`Wave*` 全部、`WindForceX=1.6`、`TeleportSpeed=40`、`MaxCoordinate=8`。

贴地段仍然不吃水平推力（防「风把落地尾巴推到身前」），跑动靠**上层先展开 → 折叠段被几何拖出 → 自身原始高度越过地面线后自然离地**，不靠临时改地面规则。

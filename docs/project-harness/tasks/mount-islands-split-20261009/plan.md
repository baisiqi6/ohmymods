## 现状与目标

现有16条获取链的新授予集中在物理land11，彩虹马保留原生活动门，实际普通时最多15条；原森林块被保留，设施在宽度规划后追加，不是把16块塞进固定500宽度。局部接缝按块数分配而非物理距离，可能集中；当前固定玩家备份尚无生成的land11，不能宣称现场森林已经被挤没。

双岛改善探索节奏和地图比例。每岛仍有完整普通森林/清地基础，不能同时把岛长减半；保留1x最低500的基础配置与现有地图倍率语义（倍率作用于原生生成基础，设施宽度后追加）。具体最小林带/设施间距在当前原生地块实际宽度核算后冻结，以生成列表和世界坐标验证，不靠岛图推断。

## 旧存档规则

- 新战役或尚未生成/访问land11、且定义尚未授予的旧战役，按新A/B目标生成。不能仅凭_islands[11]==null就判未访问，还须核visited/lastPlayed以及campaign marker/receipt。
- 已生成或已访问的旧land11维持原设施、marker、原生receipt与已付款状态；其再生成/重建沿legacy16目录与原接缝分配恢复，新A8仅用于尚未生成的新分配。不删后8条、不重排地形、不把已付款设施自动搬去13。普通旧岛上更早的授予也保持InjectOnly原址恢复。
- 第二岛的恢复/返航可用性与首次创建资格分开：已存在、当前或曾访问的B保持可恢复与返航，不因条目买完或活动过期隐藏；曾访问但slot缺失视为待诊断，不能自动新建。首次创建才要求有未授予内容；活动资格按当前战役重新读取，暂不满足不永久封死B，换战役清除旧可用性。第二岛只对仍未授予且符合原资格的B定义开放获取。已经授予的定义不因目标岛变化而重复投放/收费；若没有可新增内容，不为旧战役强行新建空岛。菜单需要说明旧战役保持历史分布，而非声称全部旧图已变8+8。
- 以后若用户要求把已生成旧岛真正迁成8+8，另定一次迁移合同：准确对象身份、原址撤出/目标生成/marker/receipt与付款的一致提交、失败退出和恢复证据。此提案不授予存档迁移或重置权限。

# 常驻时间/季节HUD

只读游戏Director当前总天数与0–24小时时钟（floor为整点，不显示分钟）；当前季节及下一季开始日从runtime LandData周期表计算，不固定16/64天。不将视觉季节过渡误认为新的日历，避免原生数据异常引发无界循环。首次第1天的季内日号为1；跨年、无下一季或零长度季节有界处理。

Display.ShowCalendarHud默认false，面板“世界”分类开关。上方居中横条，暗色半透明背景、金色天数、清晰小时，春芽/夏日/秋叶/冬雪独立缓存绘制纹理和各季颜色、下一季日期、细进度条；不使用字体emoji或注入外部字体。面板打开时HUD隐藏，关闭面板恢复；离开游戏场景/总开关关时不显示。低频缓存数据，绘制不全场扫描、不接管点击或时间。

用户已退出并授权部署上一面板候选，但本会话request_permissions未返回写权限，因此仍禁止写canonical/E；候选在当前可写目录完成验证。未修改游戏存档/配置或替换DLL。

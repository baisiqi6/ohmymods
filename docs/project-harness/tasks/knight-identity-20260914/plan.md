# 骑士独立附加存档与稳定类型

用户授权：现有骑士类型随存档固定，新招募优先补数量少的类型；额外保存 MOD 内容，原版不覆盖附加文件。实施 worker 使用本机 OMP deepseek/deepseek-v4-flash thinking=max，内置 agent 只读 review。

以本机 7.6.5-samurai-diag-20260914（9F1F61A0）为基线，保留全部既有希腊火矢、被动诊断与其他修复。不写原生字段、对象名字或压缩存档；独立文件保存 GUID/style 与完整岛快照内 uniqueID 映射。严格 scope+完整快照 SHA256 匹配，不把 NetID/instanceID 当永久标识。原版重存导致匹配失效则保留历史并重新建立当前身份，不猜测旧对象。

附加档路径为 BepInEx/config/KingdomEnhancedMod/ModSave/knight-identities.v1.json，同目录原子替换及 .bak；每 scope 最多八份快照。未知版本或损坏档拒绝普通覆盖。原生文件与附加文件不是同一事务，历史保留有限。

主机决定类型；客户端通过注册后的生命周期 nonce 请求/响应确认，不在 OnEnable 发 RPC。复用现有 5 秒骑士巡检，不加逐帧扫描；纯存储核心、运行时保存桥和网络模块分开审查。旧骑士首次迁移冻结当前可见类型或旧分配结果，此前未保存的历史类型无法追溯。原生换岛 carry 按数量重建单位，本次不承诺这些匿名随行单位逐人身份不变。

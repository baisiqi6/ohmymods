Mac Max / Codex 负责本轮造型及集成。用户将此前布棚概念指定给英雄弓箭手店，盾卫店改为借鉴原版厚重石造/大理石建筑；两店分别交付，不连带修改购买、岛隔离、存档或英雄技能。

- **#176 宝石盾卫店**：厚实石柱、过梁、内凹暗部和前后遮挡；少量重盾/宝石用于识别，无布面棚顶。当前 `shield-stone-concept-v1.png` 为建筑造型预览，无静态商人烘入。
- **#177 英雄弓箭手店**：保留布棚体积与前后层次，陈列弓、箭袋、箭束；用户追加飘带、丝巾和斗篷。衣饰克制点缀，斗篷挂棚内、丝巾放柜台、飘带在棚边，不遮主商品。当前 `hero-accessories-concept-v2.png` 为加入衣饰的预览。

预览原图与制作记录保留本机任务 `hud-gems-shop-art-20261006/shop/`，尚未修改生产 PNG、层序、商人动画或运行 DLL。预览的高分辨率细节和边缘仍需在生产制作时收口，不作为已完成的原版像素密度/透明边缘验收。

通用人物身高/接地规则已纳入 [商店素材准则](../../../development/shop-material-standard.md) 及 AGENTS.md。盾卫生产保持当前 rear/fixtures/merchant/front 四层与动画契约；两店按准则核验原生居民参照、实际地面脚线、PPU/pivot、帧表、遮挡、footprint 与付款触点后再集成。后续需要完成生产资源、必要回归、独审、PR 合并和玩家实测，分开记录；#176/#177 仍开放。

# Windows 2.4.3 x64 11.1.0 发行

用户授权发布本会话已安装、实玩的 Windows 修复链。基线 release/v9.5.13@7eed434；本批仅 Windows 2.4.3 r23537 x64。按 VERSIONING 兼容新功能最高级别一次递增 11.1.0。

## 范围与步骤

1. 从不可变 Git 源闭包还原实际 B 构建的287源、38资源；版本统一，关闭临时诊断，保留 Optimize=true。自含源码包与受管 recipe 可复建。
2. 在主线增量收敛 #250 保存协程别名、#282 航行/火枪保存修复及所需构建属性；保留 Mac Palace 与 Android 后续。旧分支不整树覆盖。
3. 核验源码/业务IL/资源差异、必要编译/测试和包完整性。正式包保持当前已玩固定 loader/runtime/generated-binding 链，不含游戏本体或存档。
4. 独立审查与精确发布关口后合并、tag、发布并读回资产。相关未验证边界明确列出，代码交付与玩家实机分开。

## 非目标与保护

不启动游戏，不修改正常安装、配置或存档。不加入临时角色计时、U英雄短路优化或未在此Windows线出现的宫廷。人口相关40–50FPS仍未解决，#275/#276继续独立。Mac11.0资产和Android不变。

## 审查与证据

GLM5.3/max 已批准阶段计划和精确历史闭包/主线增量的分离方案；两个独立只读Reviewer逐字核对源码来源。固定生成绑定的必要性由既有启动链及本次依赖读回证明，另增量审查。单次哈希/模型事件/构建原始材料留本机 windows-release-1110-20261030，公开回执只保留必要摘要。发布前仍须完成精确产物关口；本计划不预付完成状态。

# Android 密灌木与公共长状态排版

本批复用 `PatchWorld_OptionalVegetation` 的原生生成、额外实例归属与清理流程。新增一个真实默认关闭的 `DenseThicketsEnabled`，接入公共植被页；三个新目标使报告入口由 25 增至 28。Android 使用既有颜色凭据淡出，裁掉可选 FX 路径，保存只发生在三个真实配置写入点。没有新增算法副本、设置镜像、扫描或重试层。

颜色 setter 部分写入故障的独立宿主反例先红后绿。逐层写前登记 attempted，保留已确认 Applied；后续现有读取确认落地结果，先完成交接再登记下一笔。外部颜色、新生命与读取异常仍依原权责处理。最终 typed ANDROID host 22/0，PC 原 31/0，独立原反例 2/0。故障注入不代表观察到原生设备故障。

模拟器真实长状态把标题挤成竖排，因此在公共 Android `MeasureRow/DrawRow` 修复：非交互且非空的长信息在标题宽不足时上下排列，单一 metrics 负责位置、行高与帮助文字。短信息、交互卡、空值、输入和固定面板几何保持原路径，后续功能共用。实验版本由源码阶段 0.0.21 更新为最终 0.0.22，计划目标和钩子范围未变。

# Destination snapshot and exact physical witness

Links the complete production SourceProof and DestinationWitness sources. The owner/text support types are plain test boundaries; the actual gzip/UTF8/duplicate/target projection and FileStream/path classification algorithms run unchanged.

Build with `dotnet build tests/palace-destination-witness/DestinationWitness.Tests.csproj -c Release -o <private>/bin -p:BaseIntermediateOutputPath=<private>/obj/ -p:MSBuildProjectExtensionsPath=<private>/obj/`, then run the output DLL with a new private fixture directory. Optional second/third arguments are the isolated N6/case12 gzip paths; they test native owner scalar/target projection, not durable GUID binding.

Covers unknown vs explicit absent, land0 projection without source-player requirements, corruption/owner/duplicate rejection, real private FileNotFound/Present/permissions, path/link/dangling-parent rejection and read bounds. Never pass a normal game save to this suite. Does not prove native Filer runtime routing.
